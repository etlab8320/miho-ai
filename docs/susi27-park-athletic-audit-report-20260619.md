## 2. 🔴 P0 — 추천 파이프라인 전체 사망 (인프라, 산식 무관)

가장 시급. 산식 이전에 **추천 자체가 죽는다.**

- **위치:** `plugins/susi_ops/recommendation.py`
- **원인:** `_region_map()`(45–58행)이 쓰는 `_REGION_MAP`/`_REGION_MAP_PATH`가 **모듈 레벨에 정의되지 않음**. 같은 파일 `_SCHOOL_TIER`(63–64), `_TRACK_CUTS`(157–158)는 정상 정의 — `_REGION_MAP`만 2줄 누락.
- **증상:** region 인자를 받은 `susi27_recommend_candidates`가 후보 1건이라도 만들면 382행 `cand_region = _region_map()...` → `NameError: name '_REGION_MAP' is not defined`.
- **검증:** 우회로 `_REGION_MAP=None`, `_REGION_MAP_PATH=...` 주입 시 정상 40+건 산출 → 이 누락이 유일한 차단 원인.
- **이력:** HEAD 커밋 `2c97f82d6`(요강이 "현재 기준"으로 지정)부터 존재. susi_ops 분리 리팩 때 캐시 전역 소실.
- **조치:** 모듈 상단에 아래 2줄 추가 필요(수정은 별도 지시 대기):
  ```python
  _REGION_MAP_PATH = pathlib.Path(os.path.expanduser("~/.miho/academy_ops/susi_region_map.json"))
  _REGION_MAP: dict[str, str] | None = None
  ```

### A. 캠퍼스 라벨 누락 + tier 과대 (추천 노출 왜곡)
