# 2027 수시 체대 OCR/evidence 코덱스 재판독 1차 보고

작성일: 2026-06-20

## 결론

- `pdftotext` 재확인 결과 텍스트 레이어가 사실상 0줄인 핵심 이미지 PDF는 나사렛대, 배재대, 동명대 3개교다.
- 창원대, 성결대, 경북대, 공주대, 울산대, 한밭대, 호서대는 텍스트 레이어가 살아 있어 OCR 문제가 아니라 evidence/DB 문구 재정리 성격이다.
- 1차 재판독에서 즉시 코드 수정이 필요한 계산식 오류는 새로 확정하지 못했다.
- 단, 이미지 PDF 3개교는 클로드가 반드시 PDF 이미지 기준으로 다시 판독해야 한다. OCR 텍스트만 보면 숫자가 깨져 오판하기 쉽다.
- 클로드 리포트 `docs/susi27-ocr-reread-report-20260620.md`의 "호서대 코드 수정 필요" 판정은 코덱스가 반대한다. 실제 런타임 `susi27_formula_hoseo.py`는 `8.50~8.99=40`, `9.00=0` 구간표를 직접 계산하며 `test_susi27_formula_hoseo.py`가 두 경계를 모두 잠근다. 따라서 이는 코드 수정이 아니라 DB/evidence 표기 정리 항목이다.

## 클로드 재검증 지시 포인트

- 나사렛대/배재대/동명대는 cleaned text가 아니라 PDF 이미지 캡처를 직접 보고 숫자를 판독한다.
- 배재대 p.44는 OCR에서 `93`, `865`처럼 깨질 수 있으나 원문 이미지는 `92`, `85`다.
- 창원대 p.57 특기자전형 출결표를 row 337 예체능전형에 적용하면 false positive다.
- 공주대 row 99의 `record_full_score=301.5`는 오류가 아니라 `(교과900 + 출결100 + 진로5) x 30%` 구조다.
- 호서대는 `8.50~8.99=40`, `9.00=0` 구간표로 판정해야 한다.
- 호서대는 이미 런타임 코드와 테스트가 구간표를 잠그고 있으므로, 새 코드 수정 후보로 올리지 않는다.
