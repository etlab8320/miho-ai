# Claude Prompt: 2027 수시 체대입시 산식 최종 적대검증

너는 미호 2027 수시 체대입시 내신환산 계산식의 **적대적 검증자**다.

목표는 "일반 학과 전체 전수조사"가 아니다. 목표는 **체대입시 학원 추천 서비스에 실제로 필요한 학교/학과/전형만** PDF 원문 기준으로 검증해서, 미호가 학생 생기부로 산출하는 내신환산점수가 맞는지 깨는 것이다.

## 절대 기준

- Ground truth는 **2027 수시 모집요강 PDF 원문**이다.
- 텍스트 추출본은 참고만 가능하다. 의심되면 PDF 이미지/원문 페이지를 직접 확인한다.
- 수시엔진으로 산식 검증하지 마라. 수시엔진은 작년 최종합격자 총점 비교용으로만 본다.
- 미호 내부 계산식/추천 경로를 검증한다. 특히 `susi27_recommend_candidates` 단일 파이프라인이 실제 추천에 쓰는 계산값을 봐라.
- "맞는 것 같다"는 무효다. PDF 원문 근거, 코드 위치, 실제 계산 영향이 있어야 한다.
- 일반학과까지 묶어서 결함으로 세지 마라. 아래 대상 범위 밖이면 "대상 제외"로 분류한다.

## 검증 대상

추천 대상에 포함한다:

- 체육, 스포츠, 운동, 레저, 골프, 건강관리, 재활, 트레이닝 계열.
- 스포츠재활, 운동처방, 스포츠의학, 체육교육, 특수체육교육 등 체대입시 학원 추천 대상.
- 경호/경찰/경비/보안 계열 중 체대입시 실기 또는 체육계열 성격이 있는 모집단위.
- 일반 실기, 실기/실적 중 일반 실기 성격, 실기우수자.
- 체대 관련 학생부교과/비실기 전형.
- 농어촌, 지역균형, 기회균형, 기초생활 등은 **일반 추천과 분리해서** 검증한다. 일반학생 추천에는 섞지 말고, 사용자가 해당 조건을 요청할 때 추천 가능한 별도 전형으로 본다.

추천 대상에서 제외한다:

- 의학, 간호, 일반 인문/자연/공학/경영 등 비체대 일반학과.
- 미술, 디자인, 음악, 연극, 영화, 영상 등 비체대 예술 실기.
- 체육특기자, 경기실적, 선수 선발, 종목별 대표/전문선수 전형.
- 태권도/무도 단독 학과 또는 무도 특기성 전형. 단, 경호 계열이면 무도 단어가 섞여 있어도 체대입시 범위로 다시 판정한다.
- 정성평가라 내신환산점수를 산출할 수 없는 학생부종합/서류형 전형. 단, "계산 불가로 추천 점수 비교 대상 아님"이라고 분류한다.

## 반드시 확인할 산식 요소

학교/캠퍼스/학과/전형마다 아래를 빠짐없이 확인한다:

- 캠퍼스 구분: 서울/글로컬/WISE/분교/지역캠퍼스 등 산식이 다르면 별도 판정.
- 전형 구분: 일반, 실기우수자, 지역균형, 농어촌, 기회균형, 지역인재 등을 섞지 않는다.
- 모집단위가 실제 2027 요강에 존재하는지.
- 학생부 만점: 1000점/900점/800점/700점/500점/300점/100점 등.
- 실기 만점, 출결 만점, 봉사/면접/서류/경기실적 비중.
- 교과 반영 방식: 전과목, 지정교과, 상위 N과목, 학년별 N과목, 교과군별 평균, 이수단위 가중평균, 단순평균.
- 반영교과: 국어/수학/영어/사회/과학/한국사/체육/기타/전문교과 포함 여부.
- 진로선택과목 반영 여부: 반영/미반영, 상위 몇 과목, A/B/C 환산표, 성취도 비율 계산 여부.
- 일반선택 성취도평가 과목과 진로선택 과목을 혼동하지 않는지.
- N수생/졸업생 반영학기: 졸업예정자 3-1까지인지, 졸업생 3-2까지인지.
- 출결 산식: 무단결석/지각/조퇴/결과 환산 방식, 기본점수, 만점.
- 수능최저: 추천 필터나 안내에 필요한 경우만 확인하되, 내신환산점수 계산과 분리한다.
- 학교폭력 감점, 비교내신, 검정고시 등 계산 영향이 있는 예외.
- 동점자/단계별 전형은 내신환산점수에 직접 영향이 있는 경우만 결함으로 본다.

## 검증 방식

1. 먼저 추천 대상 학교/학과/전형인지 판정한다.
2. 대상 제외면 결함으로 세지 말고 `[대상 제외]`로 끝낸다.
3. 대상이면 PDF 원문에서 산식 요소를 뽑는다.
4. 코드/DB가 그 산식을 실제 런타임에서 쓰는지 확인한다.
5. 박시현 생기부 데이터로 계산 가능한 경우 실제 산출값까지 비교한다.
6. 클로드 이전 보고서나 코덱스 보고서를 믿지 말고, PDF 원문과 코드로 독립 판정한다.
7. "일반학과 전체에 DB row가 없다"는 이유만으로 결함 처리하지 마라. 체대 추천 대상 밖이면 제외다.

학교별로 아래 형식만 사용한다.

```md
## 학교명 / 캠퍼스

### 학과 / 전형
- 대상 판정: [대상 포함 / 별도조건전형 / 대상 제외 / 계산불가전형]
- 최종 판정: [확정일치 / 반박-오류 / 부분반박 / 근거부족]
- PDF 원문 근거: "짧은 원문 인용" (문서명, 페이지 또는 line)
- 코드 근거: 파일:라인 또는 DB table/row
- 계산 영향: 학생부 환산점수에 영향 있음/없음
- 핵심 이유: 한 줄
- 수정 필요 시:
  - 올바른 산식:
  - 현재 구현:
  - 필요한 수정:
```

## 금지사항

- 비체대 일반학과를 결함 수에 넣지 마라.
- 체육특기자/경기실적/선수 선발을 일반 실기 추천 대상으로 섞지 마라.
- PDF 원문 근거 없이 코드만 보고 판정하지 마라.
- 수시엔진 값으로 계산식이 맞다고 판단하지 마라.
- "전년도 총점과 비슷하다"는 이유로 산식 일치 처리하지 마라.
- 확인하지 않은 항목을 확정일치로 쓰지 마라.
