# KBO 승부예측 카드 검증 체크리스트

이 메모는 승부예측 카드에서 반복해서 확인해야 할 품질 규칙을 압축한 것이다.

## 카드 구성
- 상단 첫 화면에 키 플레이어 또는 선발 사진 1~3장을 먼저 배치한다.
- 사진은 가능하면 기사컷/액션샷을 우선하고, 단순 증명사진 느낌은 피한다.
- 예측 결과만 보이게 하지 말고, 같은 화면 안에 근거 블록이 함께 보여야 한다.

## 근거 블록
- 최소한 다음 신호를 함께 넣는다.
  - 순위/흐름
  - 최근 5경기
  - 선발 후보 또는 라인업 후보의 기록 신호
  - 필요 시 불펜 소모/구장/날씨
- 근거는 문장 설명보다 짧은 기록형 문구로 정리한다.
- "왜 이 픽인지"가 이미지 안에서 바로 읽혀야 한다.

## 렌더/검증
- HTML로 먼저 만들고 PNG로 렌더한 뒤 검증한다.
- 브라우저 캡처의 번호 오버레이, 디버그 박스, 임시 가이드가 최종 이미지에 남지 않았는지 확인한다.
- 글자 겹침, 잘림, 과도한 세로 여백, 한 화면 가독성을 반드시 본다.
- 오버레이가 보이면 전달하지 말고, 깨끗한 최종본만 다시 내보낸다.
