# Miho generic promo copy notes

Session lesson: when turning a Miho explainer into a public product-introduction image, the user wants the same visual frame but a neutral, buyer-facing product pitch.

## Copy constraints

- Remove visible owner/project/domain anchors unless the user explicitly asks for them.
  - Avoid: `맥스`, `체대입시`, `ET`, `학원`, `원장`, `강사`, `학생`, `학부모`.
  - Prefer: `사용자`, `팀`, `고객 응대`, `업무 자료`, `조직`, `내부 공유`, `고객 안내`, `보고용 자료`.
- Do not write as if reporting back to the requester. Public promo copy should not say or imply “because you asked, here is what I did.”
- Keep “developer/code review/internal architecture” language out of the visible artifact unless the target audience is technical.
- Avoid corny seduction/assistant slogans such as “당신을 홀리는 비서”. Keep the Miho/gumiho visual charm, but phrase the value as practical product benefit.

## Useful product-positioning phrases

- `말하면 이해하고, 끝까지 처리하는 업무형 AI`
- `말을 알아듣고 일을 끝내는 AI`
- `말에서 결과까지 이어주는 업무형 AI`
- `말로 요청하면 결과로 만드는 AI`
- `반복은 줄이고 업무 속도는 빠르게`
- `이해 · 정리 · 제작 · 전달`
- `요청이 결과물이 되는 과정`

## Visual emphasis

- Add explicit text-color highlights inside high-value phrases, not only decorative gradients.
- Good highlight targets: the active verb/value phrase in the title, the relationship-map value phrase, and one summary heading.
- Preserve the existing Miho fox/night visual card if the user says the current image frame is good; revise copy first before redesigning the whole layout.

## Verification checklist

1. Search the rendered HTML visible text for banned domain terms.
2. Render the PNG and inspect for lower-card clipping.
3. Verify the asset reads as a public product intro, not a dev status report or internal audit.
