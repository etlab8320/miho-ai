# Full-frame density notes for Miho promo renders

Session takeaway:
- The user wanted the *entire canvas* to feel full, not just the cards made shorter.
- Avoid fixing emptiness by only shrinking card heights; that can make the composition feel even more hollow.
- Add content density at the canvas level: hero facts, supporting chips, stacked micro-cards, and stronger visual anchors.
- For Miho promo compositions, a moonlit dark hero area and a visible profile portrait help the brand read as '미호AI' rather than a generic AI card.
- The user is sensitive to large empty bands between the top hero, middle content, and bottom cards; verify the overall frame is filled, not merely the section heights.
- Use the rendered image itself to judge balance; if the composition still feels empty, add content or restructure the layout instead of only trimming margins.
