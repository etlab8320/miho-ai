# Miho promo layout overlap notes

Session lessons for Miho AI promo images:

- The upper hero box was too tall and visually collided with the lower card section. Shorten the hero first when the upper block feels crowded; do not try to squeeze the lower cards before fixing the hero.
- Use browser inspection, not only screenshot eyeballing. Check DOM rects for the hero/title block, mid-flow block, and bottom block so you can tell whether sections actually overlap or only feel close.
- In the final pass, verify both via screenshot and browser vision that the headline is readable and the lower section has its own breathing room.
- Brand placement matters: `미호AI` should appear in the hero headline and again in a supporting label/footer if the page is a product introduction.
- Style preference from this session: the phrase “당신을 홀리는” fit the intended promo tone better than neutral language like “구미호의 감각처럼”.
