# Miho full-frame promo lesson

Source: this session's Miho AI promo-image iteration.

## What the user corrected
- Do not only shrink cards when the frame feels empty.
- Keep top / middle / bottom section gaps visually consistent.
- Keep the right/profile side as a real card with matching weight, not a loose image slot.
- Make the left header copy larger and more promotional; the user prefers bold emphasis over many tiny lines.
- Reduce lower whitespace by rebalancing the full canvas, not by trimming one section in isolation.
- Use a background that preserves the moon/fox/night feeling; the user explicitly wants that mood visible.
- Use a profile image that matches the background and mood; a generic portrait feels off.

## Practical guidance
1. Verify the live layout in a browser and compare section bounds.
2. If the composition feels sparse, add density at the canvas level:
   - hero facts / chips
   - stronger key phrases
   - a matching profile card
3. Keep the MihoAI brand name dominant in the headline and at least one supporting label.
4. Prefer concise, bold promotional copy.
5. When fixing overlap or whitespace, rebalance the whole canvas before changing individual card heights.

## Useful verification checks
- Is the top section obviously connected to the middle section?
- Are the top / middle / bottom vertical gaps visually consistent?
- Does the profile side feel like a true card with enough weight?
- Does the bottom still feel airy after the change?
- Does the moon/fox/night background still read clearly?
