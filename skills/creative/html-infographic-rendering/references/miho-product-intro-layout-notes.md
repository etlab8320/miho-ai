# Miho product intro layout notes

Session-derived notes for Miho AI promo cards.

## What the user kept correcting
- The main brand must read as **미호AI** first.
- Avoid developer-y phrasing and keep the copy promotional, not explanatory to the user.
- The phrase **"당신을 홀리는"** was preferred over literal or awkward alternatives.
- The design must feel like a product intro, not a technical audit.

## Visual direction that worked better
- Use a dark, premium hero area for the profile block.
- Keep the moon/night/fox mood visible; the user explicitly wanted the “달 아래 구미호” vibe back.
- A profile image with a mature, elegant, Korean/gumiho feel works better than a generic portrait.
- The profile card should not be empty; add keywords/tags or extra visual weight if the image leaves too much negative space.

## Layout corrections the user called out
- Do not make the top banner too tall; a huge empty header feels sparse.
- The profile area should not be visually blank.
- The middle flow section and the lower section must not visually collide.
- The lower cards should be compressed if they feel too tall or airy.

## Verification discipline
- Do not rely on text diffs or assumptions for overlap checks.
- Verify with actual browser rendering and a visual pass.
- If the user says something overlaps, inspect the live layout first, then adjust spacing/height before responding.

## Useful prompt cues
- “미호AI”, “당신을 홀리는”, “달 아래 구미호”, “밤/달빛/여우 무드”, “제품 소개 톤”
- Prefer concise, brand-forward copy over long descriptive paragraphs.
