# Miho promo layout QA notes

Session lessons for Miho product-intro images:

- The user notices full-canvas emptiness immediately. Fix by rebalancing the whole composition, not just shrinking card heights.
- Keep the section gap rhythm consistent across top / middle / bottom; uneven spacing reads as amateurish.
- The top-right profile area should be a true card with matching visual weight, not a loose image slot.
- Prefer a moon / fox / night mood background when the concept asks for a gumiho feel; avoid generic black backgrounds.
- Use a profile portrait that matches the background mood and fits cleanly inside the card.
- If the user asks for larger text, increase the actual font sizes for titles and chip labels, not just paddings or weights.
- For academy-facing promo art, use plain user-facing copy and include real workflow anchors like PACA / Peak when relevant; avoid developer jargon.
- In the flow/map section, make the central story readable first and keep lower cards from clipping by checking the rendered DOM height before the final screenshot.
