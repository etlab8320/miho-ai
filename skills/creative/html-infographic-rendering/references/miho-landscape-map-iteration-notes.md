# Miho landscape-map iteration notes

Session lessons from the Miho AI product-intro image rewrite.

## What worked
- Keep the brand name explicit in the main headline: `미호AI` must appear first.
- The user preferred a provocative promotional phrase like `당신을 홀리는` over softer metaphors.
- A dark right-side hero block with a portrait, badges, and short copy helped restore the moon/fox mood.
- Adding compact fact chips/cards inside the hero area helps fill space without making the layout feel empty.

## What failed
- Shrinking only the cards did not fix the problem when the full canvas still felt sparse.
- The user repeatedly rejected layouts where the top felt too tall or the gap between the hero and the middle section felt large.
- A large hero card with too much empty interior reads as unfinished even if the typography is technically aligned.
- The user wants the whole frame to feel densely composed, not just each individual card resized.

## Practical rules for the next revision
1. Start from the full frame, not the cards. Tune overall canvas height and section spacing together.
2. If the top feels empty, add content density inside the hero instead of only reducing height.
3. Use the portrait as part of the mood system, not a standalone placeholder.
4. Preserve the moon/fox/night identity visually; don't remove it in favor of generic promo design.
5. After each change, verify the *whole* image: top-middle-bottom spacing, not just one card.
