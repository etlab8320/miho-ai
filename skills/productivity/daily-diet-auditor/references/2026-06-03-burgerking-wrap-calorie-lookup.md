The user logged a Burger King chicken wrap but did not specify the exact variant.

- A secondary nutrition source (SnapCalorie) surfaced two relevant wrap entries:

## Practical rule

When the user logs a branded chain item but the exact SKU/variant is unclear:

1. Identify the exact variant if possible.
2. If the variant is still ambiguous, give a **reasonable range** instead of a single fake-precise number.
3. State the estimate as **대략 / 전후 / 추정**.
4. Add the item to the daily total as a range when appropriate.

## Wording guidance

- Do not imply the calorie count is exact when the menu variant is unclear.
- Do not over-explain the lookup process unless the user asks.
- Keep the final answer short and practical.
