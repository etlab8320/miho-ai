# 기록 이미지 전달 QA 노트

이 문서는 월말 테스트/학생기록/출석 이미지 전달에서 반복적으로 나온 사용자 피드백을 압축한 보조 레퍼런스다.

## 핵심 교훈

- **이미지는 한 번에 한 장만 전달한다.** 같은 결과물을 본문과 별도 경로로 이중 첨부하지 않는다.
- **캔버스는 내용에 맞게 컴팩트하게 잡는다.** 불필요한 하단 여백이나 외곽 여백을 남기지 않는다.
- 제목/부제에 **메타 설명**을 넣지 않는다. 사용자가 원하지 않은 "~만 따로 정리" 같은 문구는 제외한다.
- 배경은 기본적으로 **밝은 톤**을 유지하고, 가운데정렬 기준을 맞춘다.
- 생성 후에는 반드시 **비전 검수**로 잘림, 정렬 깨짐, 여백 과다 여부를 확인한다.

## 사용자 피드백 패턴

- "이미지 두 개씩 주고있음" → 전달 방식 오류. 최종본은 단일 이미지 1장만.
- "컴팩트 하게 사이즈를 맞춰야해" → 캔버스 높이/여백 조정이 필요.
- "메타 문구 빼" → 부제와 설명을 최소화하고 본문 데이터만 보여줘야 함.

## 적용 대상

- 학생 월말 테스트 기록표
- 학생 카드 이미지
- 출석/명단 이미지
- 일일/주간 건강 카드처럼 이미지 기반 리포트 전반
