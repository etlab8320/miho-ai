# Survey response audit session note

This note captures a user-corrected interpretation rule from a real counseling spreadsheet review.

## Important reading rule

Do **not** infer blanket dissatisfaction from a single low item when the surrounding block is positive.

Example pattern:
- `만족한다` = very positive
- `추천할 것이다` = positive
- `계속 다닐 것이다` = positive
- one isolated negative item in the same block should be treated as a **논리검토 필요** case, not automatically as a complaint.

## Recommended grouping

When the user asks to “정리해서 달라”, use these buckets:
1. 강한 불만형
2. 논리적으로 다시 봐야 하는 응답
3. 직선응답 의심형
4. 정상/보류

## Tone rule

Keep the wording neutral and factual. Prefer:
- `논리 충돌 후보`
- `질문을 잘못 이해했을 가능성`
- `재검토 후보`

Avoid overconfident labels like “불만이 있다” unless the contradiction is repeated across the satisfaction / recommendation / retention block.
