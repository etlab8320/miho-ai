# 학생용 스포츠영양학 가이드

## Overview

이 스킬은 체대입시 학생에게 필요한 스포츠영양학을 **선수식 정밀 코칭이 아니라, 실제로 지킬 수 있는 행동 규칙**으로 바꾼다.

핵심은 복잡한 영양 지식을 설명하는 것이 아니라, 학생이 오늘 당장 무엇을 먹고 언제 먹어야 하는지 3초 안에 이해하게 만드는 것이다. 목표는 감량, 유지, 회복, 실기 준비, 시험기간 컨디션 유지까지 포함한다.

## When to Use

- 체대입시 학생에게 식사/간식/회복 가이드를 줄 때
- 훈련 전후에 뭘 먹어야 하는지 추천할 때
- 감량 중인 학생의 주의사항을 정리할 때
- 운동량이 많은 날과 적은 날의 식사 기준을 나눌 때
- 편의점, 학식, 배달음식 선택을 현실적으로 안내할 때
- 상담 문구, 주간 요약, 학생용 카드 문안을 만들 때

## Core Rule Set

### 1) 학생용으로 단순화한다
학생은 길게 설명하면 안 움직인다. 아래처럼 짧고 분명하게 말한다.

- 아침은 가능하면 거르지 않기
- 훈련 전에는 소화 쉬운 탄수화물
- 훈련 후에는 단백질 + 탄수화물
- 물과 전해질 챙기기
- 야식은 회복 중심으로 정리
- 감량은 무리하지 않기

### 2) 목표에 따라 나눈다
학생 상태를 먼저 분류한다.

| 분류 | 우선순위 |
|---|---|
| 감량형 | 칼로리 과잉 방지, 단백질 확보, 폭식 방지 |
| 유지형 | 규칙성, 훈련 퍼포먼스, 회복 |
| 성장/근력형 | 충분한 탄수화물, 단백질, 수면 |
| 컨디션형 | 시험기간, 부상복귀, 피로 누적 관리 |

### 2-1) 체중관리 학생은 더 조심해서 다룬다
체중관리 학생은 단순히 "덜 먹기"로 처리하면 안 된다. 아래 기준을 우선한다.

- 급격한 감량보다 **지속 가능한 감량** 우선
- 훈련 퍼포먼스가 떨어지면 감량 속도를 늦춘다
- 단백질은 먼저 챙기고, 탄수화물은 훈련량에 맞춰 조절한다
- 야식, 음료, 군것질이 체중 관리의 핵심 변수인지 먼저 본다
- 아침을 너무 오래 비우는 방식은 피한다
- 수분 부족은 체중 착시를 만든다
- 실기 강한 날은 탄수화물을 과하게 줄이지 않는다

체중관리 학생에게는 아래처럼 말하면 된다.
- "굶는 방식 말고, 양 조절로 가자"
- "훈련 있는 날은 에너지 너무 빼면 안 된다"
- "체중보다 컨디션이 먼저 무너지면 안 된다"
- "감량은 빠르게보다 안정적으로 가는 게 낫다"

### 3) 말은 짧게, 행동은 구체적으로
권장 문장은 아래처럼 쓴다.

- "훈련 1~2시간 전: 밥/빵/바나나처럼 소화 쉬운 탄수화물"
- "훈련 직후: 단백질 + 탄수화물 먼저"
- "오늘 운동량 적으면 간식 줄이고, 식사 균형 유지"
- "감량 중이면 야식보다 회복 우선"

## Output Pattern

결과를 줄 때는 아래 순서를 우선한다.

1. 한 줄 결론
2. 오늘 기준 식사/간식 추천
3. 훈련 전후 기준
4. 주의사항 1~3개
5. 학생에게 바로 보낼 수 있는 짧은 문구

### 예시 문구

- "오늘은 훈련 전엔 가볍게, 훈련 후엔 단백질 꼭 챙기면 됩니다."
- "감량 중이면 굶는 방식 말고, 양 조절과 회복 균형이 먼저입니다."
- "실기 강한 날은 탄수화물을 너무 줄이지 마세요."
- "시험기간에는 식사 리듬이 무너지지 않는 게 제일 중요합니다."

## Common Pitfalls

1. **너무 선수식으로 설명하는 것**
   - 학생은 복잡한 숫자보다 바로 따라할 규칙이 필요하다.

2. **감량을 무조건 칭찬하는 것**
   - 체대입시 학생은 퍼포먼스가 우선이다. 무리한 감량은 역효과가 날 수 있다.

3. **운동량 차이를 무시하는 것**
   - 훈련 많은 날과 적은 날의 식사 기준은 달라야 한다.

4. **의학적 조언처럼 쓰는 것**
   - 질환, 약물, 섭식장애, 성장 문제는 전문의/영양사 영역으로 분리한다.

## Verification Checklist

- [ ] 학생이 바로 이해할 수 있는 짧은 문장인가
- [ ] 훈련 전/후 식사 기준이 들어갔는가
- [ ] 감량/유지/성장 중 어느 쪽인지 구분했는가
- [ ] 학생이 실제로 살 수 있는 음식 예시를 제시했는가
- [ ] 과도한 일반화나 의료 조언이 섞이지 않았는가
- [ ] 상담용, 카드용, 주간 리포트용으로 재사용 가능한가
