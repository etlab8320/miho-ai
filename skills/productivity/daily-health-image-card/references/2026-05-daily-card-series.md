# 2026-05 Daily Health Card Series Notes

Session-specific notes from the first preserved run of the daily health image card workflow.

## What the user liked

- Bright, clean, readable card style.
- Large Korean text.
- Discord-ready PNG output.
- Neutral tone for health feedback.
- Clear inclusion of:
  - date
  - weight
  - meals
  - exercise
  - judgment
  - next-step point
  - total calories when relevant

## Important user preference captured here

- When the user asks for "from the day you started recording" or similar, provide all already-generated daily cards in chronological order.
- Do not answer with only the latest day if prior cards already exist.
- Keep the phrasing calm and non-shaming; avoid words like "망했다".
