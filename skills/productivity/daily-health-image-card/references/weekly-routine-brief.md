# Weekly Health Routine Brief

Session-specific notes for the weekly health routine image requested on Monday morning.

## Goal

Create a single polished weekly health routine image for **월~토** that includes:

- recent weight
- blood sugar / blood pressure routine
- day-by-day meal structure
- day-by-day exercise / activity structure
- a calm judgment and one-line diet direction

## Layout expectation

- One image, not a chat transcript.
- Bright, clean, report-style composition.
- Recent weight must be visible near the top.
- Use clear week-level sections:
  - top summary chips
  - daily check-in rules
  - meal structure rules
  - 월~토 routine cards
  - closing verdict strip

## Rule of thumb

- The weekly image is a **routine planner**, not a daily log.
- Use a **single report page** and keep the tone practical.
- If the user asks to add or change one field in the scheduled weekly/daily image, patch the existing cron job / existing layout rather than generating a separate redesign unless explicitly requested.
- Keep the title/report name prominent and Korean-first.

## Data to include by default

- Recent weight (latest reliable value)
- Blood pressure routine: when to measure, how to measure, and how often
- Blood sugar routine: which days or conditions to check
- Meal structure for 월~토
- Workout structure for 월~토
- One-line closing judgement

## Verification

- The image fills the frame.
- No bottom clipping.
- The weekly routine is legible on Discord.
- The report reads as one complete plan, not stacked random panels.
